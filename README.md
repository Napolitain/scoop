# Napolitain Scoop bucket

Add the bucket:

```powershell
scoop bucket add napolitain https://github.com/Napolitain/scoop
```

Install an app:

```powershell
scoop install napolitain/baremetal-gaming
scoop install napolitain/winbash
```

The `winbash` manifest is synchronized automatically from the rolling
[`continuous`](https://github.com/Napolitain/winbash/releases/tag/continuous)
prerelease.
